# qBittorrent 5.1 中文设置清单

适用于 Debian 13 官方 `qbittorrent-nox` 5.1.x。不同小版本的文字或位置可能略有变化。

本文数值针对 1 核、1～1.5 GB 内存、小硬盘 VPS，并以 BTSCHOOL 2026-07-25 当时 25 MB/s 上传上限为背景。站点规则变化后必须调整。

## 一、行为

- 用户界面语言：简体中文
- 删除 Torrent 时提示确认：开启
- 日志文件：开启
- 日志备份大小：默认或约 65 KiB
- 删除旧日志：1 个月
- 不需要修改其他选项

## 二、下载

添加 Torrent 时：

- Torrent 内容布局：原始
- “添加到队列顶部”：关闭
- “不要自动开始下载”：建议开启；熟悉后可在单次添加窗口手动选择开始
- Torrent 停止条件：无
- 合并 Tracker 到已有 Torrent：关闭
- 完成后删除 `.torrent` 文件：关闭
- 为所有文件预分配磁盘空间：关闭
- 为不完整文件添加 `.!qB`：可关闭

保存管理：

- 默认 Torrent 管理模式：手动
- 默认保存路径：`/srv/qbt/downloads`
- 保存未完成的 Torrent 到：开启
- 未完成路径：`/srv/qbt/incomplete`
- 监控文件夹：留空
- 邮件通知：关闭
- 新增/完成 Torrent 时运行外部程序：关闭

不要开启“完成后删除”，否则容易违反 H&R。

## 三、连接

- Peer 连接协议：TCP 和 µTP
- 用于传入连接的端口：与安装脚本 `--peer-port` 相同，默认 `49160`
- 每次启动使用随机端口：关闭
- UPnP/NAT-PMP：关闭

连接限制：

- 全局最大连接数：300
- 每个 Torrent 最大连接数：30
- 全局上传窗口数上限：20
- 每个 Torrent 上传窗口数上限：4

I2P：关闭。

代理服务器：

- 类型：无
- 对 BitTorrent、RSS、常规目的使用代理：全部关闭

IP 过滤：关闭，除非站点明确要求。

## 四、速度

全局速度限制：

- 上传：`18000 KiB/s`
- 下载：`30000 KiB/s`

备用速度限制：

- 上传：`18000 KiB/s`
- 下载：`30000 KiB/s`
- 计划启用时间：关闭

速度限制选项：

- 对 µTP 协议进行速度限制：开启
- 对传送总开销进行速度限制：开启
- 对本地网络用户进行速度限制：开启

说明：

- `18000 KiB/s` 约 17.6 MiB/s，为 25 MB/s 站点上限留出余量；
- `30000 KiB/s` 是保护单核、小内存和小磁盘，不是站点下载限制；
- 不要因为 VPS 宣传 10 Gbps 就把 qBittorrent 上传改成无限；
- 若目标站点规则更严格，以更严格的上限为准。

## 五、BitTorrent

隐私：

- DHT：关闭
- PeX：关闭
- 本地用户发现：关闭
- 加密模式：允许加密
- 匿名模式：关闭

私有种子通常由客户端自动禁用 DHT/PeX，但全局关闭更适合纯 PT 专用机。

队列：

- 最大活跃检查 Torrent 数：1
- Torrent 排队：开启
- 最大活动下载数：1
- 最大活动上传数：120
- 最大活动 Torrent 数：120
- 慢速 Torrent 不计入限制：关闭

做种限制：

- 分享率达到后停止：关闭
- 总做种时间达到后停止：关闭
- 不活跃做种时间达到后停止：关闭

Tracker：

- 自动附加 Tracker 到新下载：关闭
- 自动附加 URL 中的 Tracker：关闭

绝对不要向 PT 私有种子追加公共 Tracker。

## 六、WebUI

Web 用户界面：

- IP 地址：`127.0.0.1`
- 端口：`8080`
- UPnP/NAT-PMP 转发 WebUI：关闭
- 使用 HTTPS 而不是 HTTP：关闭（Caddy 已负责 HTTPS）

验证：

- 用户名：改成自定义用户名
- 密码：至少 16 位强密码
- 对本地主机客户端跳过身份验证：关闭
- 对白名单子网跳过身份验证：关闭
- 连续失败后禁止客户端：5
- 禁止：3600 秒
- 会话超时：3600 秒

安全：

- Clickjacking 保护：开启
- CSRF 保护：开启
- Cookie 安全标志：开启
- Host Header 属性验证：开启
- 服务器域名：`你的子域名;127.0.0.1`

第二台示例：

```text
qbt2.example.com;127.0.0.1
```

反向代理：

- 启用反向代理支持：开启
- 受信任的代理列表：`127.0.0.1`

其他：

- 备用 WebUI：关闭
- 自定义 HTTP Headers：关闭
- 动态域名更新：关闭

不要把服务器域名长期设置为 `*`，不要关闭 CSRF/Host Header 验证来“解决登录问题”。

## 七、高级

新手保持默认。重点确认：

- 网络接口：任意接口
- 可选 IP 地址：所有地址
- 验证 HTTPS Tracker 证书：开启
- SSRF 缓解：开启
- 允许同一 IP 的多个连接：默认关闭
- 内存、磁盘缓存：保持自动

不要照抄来历不明的“高性能参数”。1 核小内存 VPS 连接数过高只会增加负载。

## 八、保存后验证

服务器执行：

```bash
ss -lntup | grep -E '8080|49160'
```

期望：

- WebUI 仅监听 `127.0.0.1:8080`；
- BT 端口监听公网 IPv4/IPv6 的 TCP 和 UDP；
- UFW 没有放行 8080；
- 站点显示“可连接：是”。

WebUI 测试：

```bash
curl -I https://你的子域名
```

应返回 HTTP 200、HTTP/2 200 或登录页的正常响应。

## 九、不同站点

一个 qBittorrent 全局速度限制会同时作用于所有站点。若同时使用多个 PT：

- 采用所有站点中最严格的速度上限；
- 每个站点都确认客户端白名单；
- 不混入公共 Tracker；
- 分别记录每个站点 H&R；
- 不把某站点的私有 `.torrent` 发给其他账号或服务器。
