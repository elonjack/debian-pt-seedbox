# qBittorrent 中文设置清单

适用于 Debian 12 官方 qBittorrent 4.5.x 和 Debian 13 官方 qBittorrent 5.1.x。两个版本的标签名称、顺序可能略有不同；找不到某一项时不要盲填，先看当前版本帮助。

以下数值适合 1 核、1～1.5 GiB 内存、小硬盘 VPS。站点规则比本清单优先。

## 下载

- Torrent 内容布局：原始
- 默认 Torrent 管理模式：手动
- 默认保存路径：`/srv/qbt/downloads`
- 保存未完成的 Torrent 到：开启
- 未完成路径：`/srv/qbt/incomplete`
- 完成后删除 `.torrent`：关闭
- 预分配全部文件：关闭
- 监控文件夹：留空
- 邮件通知：关闭
- 新增/完成时运行外部程序：关闭

不要开启“完成后停止/删除”，否则容易违反 H&R。

## 连接

- Peer 协议：TCP 和 μTP
- 传入连接端口：与安装时 `--peer-port` 相同，默认 `49160`
- 随机端口：关闭
- UPnP/NAT-PMP：关闭
- 代理类型：无
- I2P：关闭
- IP 过滤：关闭，除非站点明确要求

小机器建议：

- 全局最大连接数：300
- 每 Torrent 最大连接数：30
- 全局上传槽：20
- 每 Torrent 上传槽：4

## 速度

必须按目标站点当前规则设置。示例站点若规定上传不超过 25 MB/s，可以留余量：

- 上传：`18000 KiB/s`（约 17.6 MiB/s）
- 下载：`30000 KiB/s`
- 备用速度：同上
- 计划备用速度：关闭
- μTP 限速：开启
- 传输总开销计入限速：开启
- 本地网络用户限速：开启

站点没有下载限速并不代表小 VPS 应设为无限；30 MiB/s 有助于保护单核 CPU、小内存和共享磁盘。

## BitTorrent

隐私：

- DHT：关闭
- PeX：关闭
- 本地用户发现：关闭
- 加密模式：允许加密
- 匿名模式：关闭

队列：

- 最大活动检查数：1
- Torrent 排队：开启
- 最大活动下载数：1
- 最大活动上传数：120
- 最大活动 Torrent 数：120
- 慢速 Torrent 不计入限制：关闭

做种限制全部关闭：

- 分享率达到后停止：关闭
- 总做种时间达到后停止：关闭
- 不活跃做种时间达到后停止：关闭

Tracker：

- 自动附加 Tracker 到新下载：关闭
- 自动附加 URL 中的 Tracker：关闭

绝对不要向 PT 私有种子追加公共 Tracker。

## WebUI

基础：

- IP 地址：`127.0.0.1`
- 端口：`8080`
- WebUI UPnP/NAT-PMP：关闭
- qBittorrent 内置 HTTPS：关闭（HTTPS 由 Caddy 提供）

身份验证：

- 用户名：改成自己的用户名
- 密码：至少 16 位独立强密码
- 本地主机跳过身份验证：关闭
- 白名单子网跳过身份验证：关闭
- 连续失败次数：5
- 禁止时间：3600 秒
- 会话超时：3600 秒

安全：

- Clickjacking 保护：开启
- CSRF 保护：开启
- Cookie 安全标志：开启
- Host Header 验证：开启
- 服务器域名：`你的完整子域名;127.0.0.1`

示例：

```text
qbt2.example.com;127.0.0.1
```

示例域名必须替换成自己的。

反向代理：

- 启用反向代理支持：开启
- 受信任代理：`127.0.0.1`

其他：

- 备用 WebUI：关闭
- 自定义 HTTP Headers：关闭
- 动态域名更新：关闭

不要把服务器域名长期设为 `*`，不要关闭 CSRF、Host Header 或登录验证来“解决问题”。

## 高级

新手保持默认，重点确认：

- 网络接口：任意接口
- 可选 IP：所有地址
- 验证 HTTPS Tracker 证书：开启
- SSRF 缓解：开启
- 允许同 IP 多连接：默认关闭
- 内存、磁盘缓存：自动

## 保存后验证

服务器执行：

```bash
ss -lntup | grep -E '8080|49160'
ufw status verbose
```

期望：

- WebUI 只监听 `127.0.0.1:8080`；
- BT 端口监听公网 TCP 和 UDP；
- UFW 不放行 8080；
- 站点显示客户端可连接；
- 域名返回正常登录页。

如果实际 BT 端口不是 49160，请替换命令中的数字。

## 版本差异

Debian 12：

- qBittorrent 4.5.x 首次默认口令原本是 `adminadmin`；
- 本项目安装器会在 Caddy 开放前自动换成随机强密码；
- 部分 5.x 才有的 WebUI 选项可能不存在，跳过不存在的非关键界面项。

Debian 13：

- qBittorrent 5.1.x 原生使用临时密码；
- 本项目同样会自动换成安装专用随机密码；
- 首次登录不需要从 journalctl 抄临时密码。

无论哪个版本，最终都要用 PT 站白名单确认。
